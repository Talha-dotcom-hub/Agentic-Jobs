# Security Policy

## Supported versions

Security fixes are applied to the current default branch. No older release branches are currently designated as supported.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues or discussions.

Use GitHub's **Report a vulnerability** flow in the repository Security tab when private vulnerability reporting is available. Include:
- the affected commit or file path;
- a concise description of the security impact;
- reproducible steps or a minimal proof of concept;
- any suggested mitigation.

Do not include real user resumes, credentials, session tokens, private keys, or production database exports in a report.

## Response expectations

The maintainers will review reports as soon as practical. No response-time or remediation-time SLA is currently offered. Please allow reasonable time for triage and a coordinated fix before public disclosure.
